# Generated audio pack

Everything in this directory is generated by the committed Node scripts under
`tools/audio/`. Do not hand-edit the WAV files; edit the synthesizer or the
sound definitions and run:

```bash
npm run assets
```

`npm run assets` builds the art pack and the audio pack together and rewrites
`src/data/asset-manifest.json`, which `PreloadScene` reads. The generator also
checks that the `SfxName` and `MusicName` unions in
`src/services/audio-service.ts` match the generated keys, so a renamed or
missing sound fails the build instead of failing at runtime.

## Contents

- `sfx/` — 32 one-shot effects: movement, rock combat, item use, pickups,
  enemy damage, and the full boss move set.
- `music/` — three looping themes: `music-title` (title, options, results),
  `music-mines` (levels 1–4), and `music-boss` (Great Worm arena).

All files are 16 kHz, 16-bit mono PCM WAV. The pack contains 35 files and is
about 1.2 MB uncompressed. Every buffer is DC-offset corrected and normalized
below full scale by the generator, so no file clips or starts with a click.

## Synthesis

The pack is original: waveforms, envelopes, noise, and simple FM pairs are
generated in code, with a small deterministic PRNG for noise so repeated runs
produce identical bytes. No samples, loops, or third-party sound libraries are
used.

## Regeneration

Run `npm run assets` after changing any generator file. Commit the regenerated
WAVs, `public/assets/`, and `src/data/asset-manifest.json` together with the
generator change so the repository always contains a buildable pack.
