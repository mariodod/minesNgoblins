# Generated asset pack

Everything in this directory is generated by the committed Node scripts under
`tools/assets/`. Do not hand-edit the PNG or XML files; edit the generator and
run:

```bash
npm run assets
```

The generator is deterministic and writes the art pack, the
[audio pack](../audio/README.md), and `src/data/asset-manifest.json`.
`PreloadScene` reads the manifest to load every image, spritesheet, and sound
and to register all animations, so adding an asset does not require a second
hardcoded asset list.

## Contents

- `sprites/` — nine player skins (8 frames each, 16×24), six enemy sheets
  (6 frames each), the Great Worm head and shockwave sheets, and static boss
  parts (burrow hole, worm segment).
- `tiles/` — five themes: `shaft-entrance`, `goblin-tunnels`,
  `crystal-caverns`, `deep-vein`, and `worm-lair`. Each theme supplies stone,
  wood, background, pillar, beam, and stalactite tiles.
- `items/`, `props/`, `fx/`, `ui/`, and `title/` — pickups, crates and props,
  combat effects, interface pieces, and the title backdrop.
- `fonts/pixel-5x7.png` and `fonts/pixel-5x7.xml` — the original 5×7 bitmap
  font used by `PixelText`.

The current pack contains 56 images, 17 spritesheets, 63 animations, and one
bitmap font with 95 glyphs.

## Art direction

The art is original pixel work authored in code with a shared palette. It uses
one 16×24 player silhouette with per-skin palette recolors, 6-frame animation
sheets for standard enemies, and a larger authored head for the Great Worm.
Every frame is aligned to the 480×270 internal canvas and uses hard pixel edges
with no antialiasing or runtime texture generation.

## Regeneration

Run `npm run assets` after changing any generator file. Commit the regenerated
PNGs, the font files, and `src/data/asset-manifest.json` together with the
generator change so the repository always contains a buildable pack.
