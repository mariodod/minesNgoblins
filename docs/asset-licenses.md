# Asset and dependency licenses

This file is the inventory promised by the M6 acceptance criteria. The pack
READMEs remain the source of truth for how the assets are generated.

## Original assets

Every runtime asset in this repository is original work created for Mines &
Goblins by the project authors.

| Asset group     | Location                                       | Origin                                                   |
| --------------- | ---------------------------------------------- | -------------------------------------------------------- |
| Sprites         | `public/assets/sprites/`                       | Generated by `tools/assets/` in code                     |
| Tiles           | `public/assets/tiles/`                         | Generated by `tools/assets/` in code                     |
| Items and props | `public/assets/items/`, `public/assets/props/` | Generated by `tools/assets/` in code                     |
| Effects and UI  | `public/assets/fx/`, `public/assets/ui/`       | Generated by `tools/assets/` in code                     |
| Title art       | `public/assets/title/`                         | Generated by `tools/assets/` in code                     |
| Bitmap font     | `public/assets/fonts/`                         | Original 5×7 glyphs generated by `tools/assets/font.mjs` |
| Sound effects   | `public/audio/sfx/`                            | Synthesized by `tools/audio/` with no samples            |
| Music           | `public/audio/music/`                          | Synthesized by `tools/audio/` with no samples            |

No third-party sprites, tilesets, textures, fonts, recordings, samples, or
music loops are included. No asset was downloaded from an asset store or a
generative model.

The repository license is currently `UNLICENSED` (all rights reserved). If a
public license is chosen later, it applies to these original assets as well.

Regeneration instructions:

- [Art pack](../public/assets/README.md)
- [Audio pack](../public/audio/README.md)
